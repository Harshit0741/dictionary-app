

# **Q1 – Leveraging AI in Front-End Delivery**

In a startup, AI tools like **GitHub Copilot** and **Figma’s AI** assistant can speed up front-end development. **GitHub Copilot** suggests code snippets and functions, reducing repetitive coding, while **Figma's AI** helps auto-adjust designs for responsive layouts. These tools allow developers to focus on more complex tasks, ensuring fast delivery without compromising on code quality. They optimize development and design processes, ensuring faster shipping of features while maintaining consistency and accuracy.


# **Q2 – Inventing an AI Feature for Class 11 Students**

**Feature 1**: **AI-Powered Problem Solver**
The AI guides students through physics problems step by step, offering hints and alternative methods to improve understanding.

**Feature 2**: **AI-Based Concept Explorer**
It analyzes performance, identifies weak areas, and recommends tailored resources like videos or quizzes to reinforce learning.

**User Journey**:

1. Student logs in -> selects Physics.
2. They input a problem -> AI guides them.
3. AI tracks weaknesses -> recommends targeted content.
4. AI adapts learning path based on progress.
